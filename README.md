# Portfolio — Phase 5

This package is the Phase 5 polished version of the HTML/CSS/JavaScript portfolio.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript

## Files
- `index.html` — page structure and content
- `style.css` — primary styles
- `responsive.css` — responsive layout
- `animations.css` — motion and interaction styles
- `main.js` — navigation, filtering, validation, reveal effects, back-to-top, tech interaction
- `projects.js` — project data
- `animations.js` — lightweight animation initialization

## Before deployment

Replace the remaining placeholders:
- `[YOUR NAME]`
- `[YOUR EMAIL]`
- GitHub URL
- LinkedIn URL
- project names/descriptions/images
- project live URLs
- project GitHub URLs
- favicon and Open Graph image
- `og:url` with the real deployed domain

Do not publish placeholder contact links.

## Final checks

1. Open `index.html` locally.
2. Test desktop navigation.
3. Test the mobile menu at narrow widths.
4. Test all section links.
5. Test project filters.
6. Test the contact form with empty and invalid fields.
7. Confirm keyboard focus is visible.
8. Confirm the back-to-top control appears after scrolling.
9. Replace all placeholder content.
10. Confirm all project images exist.
11. Open browser DevTools and check for console errors.
12. Test on desktop, tablet, and mobile.
13. Deploy to GitHub Pages, Vercel, or another static host.

## Important

The contact form currently performs client-side validation only. It does **not** send email or store submissions. Connect it to a form service or backend later if actual message delivery is required.
